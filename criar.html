🚀 Transforme seu Conversor de Moeda em App Desktop com Electron.js

✅1. Estrutura de Pastas

Crie a seguinte estrutura de arquivos:

conversor-moeda/
├── index.html
├── main.js
├── package.json
└── preload.js (opcional)

✅2. Crie o package.json

Rode no terminal (dentro da pasta conversor-moeda):

npm init -y

Depois, instale o Electron:

npm install electron --save-dev

Depois, Instale o electron-builder:

npm install --save-dev electron-builder

Atualize o package.json para incluir o ponto de entrada:


    {
{
    "name": "conversor-moeda",
    "version": "1.0.0",
    "description": "Aplicativo Electron para conversão de moedas",
    "main": "main.js",
    "scripts": {
    "start": "electron ."
    },
    "author": "",
    "license": "ISC",
    "devDependencies": {
    "electron": "^27.0.0"
    }
}

}

✅3. Crie o main.js

Esse arquivo inicializa a janela do app:

const { app, BrowserWindow } = require('electron');
const path = require('path');

function createWindow() {
    const win = new BrowserWindow({
        width: 500,
        height: 700,
        webPreferences: {
            preload: path.join(__dirname, 'preload.js'), // opcional
        },
    });

    win.loadFile('index.html');
    // win.webContents.openDevTools(); // descomente para depurar
}

app.whenReady().then(createWindow);

app.on('window-all-closed', () => {
    if (process.platform !== 'darwin') app.quit();
});

app.on('activate', () => {
    if (BrowserWindow.getAllWindows().length === 0) createWindow();
});

✅4. (Opcional) preload.js

Arquivo opcional para acessar o DOM com segurança:

// preload.js
window.addEventListener('DOMContentLoaded', () => {
    // Aqui você pode acessar o DOM se quiser
});

✅5. Use seu index.html

Pegue o HTML do conversor de moeda e salve como index.html no mesmo diretório.

✅6. Execute a aplicação

No terminal, digite:

npm start

Seu conversor vai abrir em uma janela de desktop com Electron!

✅Extras (Opcional)

  • 🔧 Embutir ícone personalizado para o app
  • 📦 Empacotar com electron-packager ou electron-builder
  • 🧭 Adicionar menus personalizados ou atalhos nativos
